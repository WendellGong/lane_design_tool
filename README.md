# 自动驾驶赛道设计器（Autonomous Track Designer）

面向自动驾驶 / 智能网联测试场景的可视化赛道搭建工具：在浏览器中拖拽元素即可绘制测试赛道，
一键保存为 JSON，并可随时加载复用。前端使用原生 HTML + SVG + JavaScript，后端使用 Python（Flask）。

运行：主目录下python backend/app.py 即可


## 功能特性

- **拖拽式绘图**：从左侧元素库拖入画布，画布内支持移动、旋转、缩放，网格吸附
- **物理单位建模**：所有道路以“米”为单位，渲染比例固定为 **12 px = 1 m（PPM）**，尺寸可按真实尺度复算
- **车道宽度严格遵循国标**：提供 3.75 / 3.50 / 3.25 / 3.00 / 2.80 m 五档（见下表），道路总宽随车道数自动计算
- **模块出入口衔接（Port 磁吸，保持原姿态）**：每个道路模块都带标准化出入口，拖动模块靠近其他出入口时，**不再强制旋转，仅平移使两端口精确重合**，元素原有角度（姿态）保持不变；选中模块时青色标记显示全部出入口
- **吸附后自动组合**：磁吸成功的两个模块自动合并为一个“组合模块”，之后整体移动、相对位置锁定；支持**空白处左键拖拽框选（marquee）多个元素**，并通过**右键菜单 / 属性面板组合或取消组合**
- **弯道 / 匝道曲率与弧度自由输入**：中心线半径 Rc（10–2000 m，曲率 κ = 1/R）与弧度（1–360°）均改为数字框自由填写，可左 / 右转
- **环岛双车道出入口**：环岛各出入口宽度按 **2 条车道**建模，环道车道数可在 1–3 之间配置（默认 2）
- **多车道路口**：十字路口每方向 1–4 车道（含进口导向箭头、斑马线），丁字路口主路每方向 1–3、支路 1–3 车道
- **国标泊车位**：按**单个车位**的国标长宽（默认 2.5 m × 5.3 m）与通道宽（默认 6.0 m）建模，整体尺寸随车位数量自动推导，不再把固定区域均分；支持垂直式 / 平行式
- **7 类赛道元素**：直道、弯道、匝道、环岛、丁字路口、十字路口、泊车位
- **6 类交通参与者**：轿车、SUV、卡车、巴士、两轮车、**行人（小人）**；车辆支持车身颜色与完整动力学参数，行人支持上衣颜色与行走 / 站立姿态
- **23 种 GB 交通标志**：覆盖 GB 5768 常用警告（三角黄底）、禁令（红圈 / 八角停车让行 / 倒三角减速让行）、指示（蓝底）标志，限速值可自定义
- **6 类国标障碍物**：雪糕筒（锥形交通路标）、水马、防撞桶、波形护栏、施工围挡、警示灯
- **4 类交通信号灯**：机动车信号灯、方向箭头灯、闪光警告灯、车道信号灯（红叉 / 绿箭头），灯色可切换并带点亮光晕
- **图层层级**：右键菜单「置于顶层 / 置于底层」（Ctrl+] / Ctrl+[）；绘制顺序即 `elements` 数组顺序，**道路元素默认沉到最底层**，车辆、信号灯、标志、障碍始终压在路面之上
- **方向键微调**：上下左右方向键以 1 px（Shift 时 10 px）微调选中元素位置
- **保存 / 加载**：后端持久化到 `tracks/` 目录，支持列表、加载、删除；分组关系（gid）一并保存；另支持本地 JSON 文件的导入 / 导出
- **撤销 / 重做**：最多 50 步历史；丰富的键盘快捷键
- **深蓝科技风**界面，响应式布局，适配不同屏幕宽度

## 国标车道宽度（一条机动车道）

车道宽度档位依据 CJJ 193-2012《城市道路路线设计规范》表 5.3.1，并纳入交叉口进口道相关规定：

| 车道宽 | 适用场景 | 依据 |
|---|---|---|
| **3.75 m** | 设计速度 > 60 km/h 的大型车 / 混行车道 | CJJ 193 表5.3.1 |
| **3.50 m** | 设计速度 ≤ 60 km/h 的城市混行车道（默认） | CJJ 193 表5.3.1 |
| **3.25 m** | 设计速度 ≤ 60 km/h 的小客车专用车道 | CJJ 193 表5.3.1 |
| **3.00 m** | 交叉口进口道（新建） | GB 50647 / GB/T 36670 |
| **2.80 m** | 交叉口进口道改建极限值（无大型车） | GB 50647 / GB/T 36670 |

道路总宽 = 车道数 × 单车道宽。例如双向 4 车道、3.50 m 档：总宽 = 4 × 3.50 = 14 m，渲染像素 = 14 × 12 = 168 px。

## 弯道曲率与弧度（自由输入）

曲率以**中心线半径 Rc** 表示，曲率 κ = 1 / Rc（单位 /m）。Rc 与弧度均为**数字框自由输入**（Rc 范围 10–2000 m，弧度 1–360°），不再受预设档位限制。下表给出 CJJ 193-2012 表 6.3.2 圆曲线常用 / 最小半径，供输入时参考：

| 参考中心线半径 Rc | 20 | 40 | 70 | 100 | 150 | 200 | 300 | 400 | 650 | 1000 | 1600 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 曲率 κ ≈ | .0500 | .0250 | .0143 | .0100 | .0067 | .0050 | .0033 | .0025 | .0015 | .0010 | .0006 |

- 几何以中心线半径 Rc 推导：内缘半径 r = Rc − W/2，外缘半径 R = Rc + W/2（W = 车道数 × 车道宽），包围盒紧贴图形
- 匝道默认单车道、较小半径；弯道与匝道均支持左 / 右转弯方向
- 输入任意非档位值（如 Rc = 55 m、弧度 73°）均可正确渲染并复算尺寸

## 模块出入口、磁吸衔接与分组

- 每个道路模块定义若干**出入口（Port）**，包含位置、法线方向（normal，度）与端口宽度
- 拖动模块时，系统计算各出入口的世界坐标，若与其他模块出入口距离小于约 18 px，则选中最近的一对：
  - **保持元素当前旋转角度（原姿态）不变，不做任何旋转**
  - 仅平移被拖模块，使两端口精确重合，从而在不改变姿态的前提下完成对接
- 磁吸成功并松开鼠标后，两个模块**自动合并为一个组合模块（写入相同 gid）**，此后拖动其中任一元素，整组一起移动、相对位置锁定
- 按住 **Ctrl** 拖动可临时关闭磁吸；脱离阈值范围即恢复自由移动
- 直道、弯道、匝道、环岛、丁字 / 十字路口均带出入口，可任意组合衔接；同组元素之间不会重复磁吸

### 框选、组合与取消组合

- **框选（marquee）**：在画布空白处按住左键拖拽，出现青色虚线选择框，松开后与选择框相交的元素全部选中；空白处单击则取消选中
- **Shift + 点击**元素可向当前选择中追加 / 移除单个元素
- 多选后可在右侧属性面板点击“组合为模块 / 取消组合”，或在元素上**右键**唤出上下文菜单：
  - 组合为模块 / 取消组合 / 复制（Ctrl+D）/ 删除
- 取消组合后，各元素恢复独立，可自由移动与旋转
- 平移画布：中键拖拽，或按住 **空格 / Alt** 时左键拖拽

### 国标泊车位

- 泊车位按**单个车位**建模，默认车位宽 2.5 m、车位长 5.3 m（小型机动车垂直式常用尺寸），通道宽 6.0 m，均可在属性面板调整
- 整体尺寸由“车位数量 × 单车位尺寸 + 通道”推导（垂直式：宽 = 数量×车位宽，高 = 车位长 + 通道宽；平行式：宽 = 数量×车位长，高 = 车位宽 + 通道宽），不再把固定区域均分
- 每个车位绘制独立车位线与挡车器，通道区标注实际通道宽度

## 快速开始

### 1. 环境要求

- Python 3.9+
- 安装依赖（仅 Flask）：

```bash
cd autonomous_track_designer
pip install -r backend/requirements.txt
# 或：pip install flask
```

### 2. 启动服务

```bash
python backend/app.py
```

看到 `Running on http://127.0.0.1:5000` 后，浏览器打开：

```
http://127.0.0.1:5000
```

### 3. 开始设计

1. 从左侧元素库**拖拽**元素到画布（也可点击选中后用手柄调整）
2. 选中元素后在右侧**属性面板**修改车道宽、曲率、弧度等参数
3. 拖动模块靠近其他出入口，即可看到**自动磁吸衔接**（Ctrl 可临时关闭）
4. 点击顶部 **保存** 命名后存入服务器；**加载** 可从列表恢复
5. 无需后端时，可用 **导出 JSON / 导入 JSON** 在本地文件间流转

## JSON 数据结构

```json
{
  "version": "1.1",
  "meta": {
    "name": "示例赛道",
    "grid": 20,
    "pixels_per_meter": 12,
    "saved_at": "2026-11-06 12:00:00"
  },
  "view": { "scale": 1, "tx": 380, "ty": 435 },
  "elements": [
    {
      "id": "el_xxxx",
      "type": "lane",
      "subtype": "straight",
      "x": 100,
      "y": 100,
      "rotation": 0,
      "w": 168,
      "h": 144,
      "gid": "g_yyyy",
      "props": {
        "lanes": 4,
        "laneW": 3.5,
        "length_m": 12,
        "twoWay": true
      }
    }
  ]
}
```

- `version`：当前为 `1.1`；加载旧版 `1.0` JSON 时自动兼容（缺失的 `gid` 视为未分组）
- `type`：`lane` / `car` / `sign` / `obstacle` / `light` 五大类
- `subtype`：具体元素类型，决定 SVG 渲染与可编辑属性
- `x / y / rotation`：元素中心坐标（像素）与旋转角度（度）
- `w / h`：元素边界尺寸（像素，= 物理尺寸 × PPM）
- `gid`：分组标识，**相同 gid 的元素属于同一组合模块**；未分组时该字段为空 / 不存在
- `props`：元素专属参数，**道路参数均为物理单位（米 / 度）**，如车道宽 `laneW`、长度 `length_m`、曲率半径 `Rc`、弧度 `angle`、泊车位的 `stallW / stallL / aisleW`

## 后端 API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/tracks` | 已保存赛道列表（含元素数、更新时间、大小） |
| GET | `/api/tracks/<name>` | 加载指定赛道 |
| POST | `/api/tracks/<name>` | 保存（覆盖）赛道，请求体为完整设计 JSON |
| DELETE | `/api/tracks/<name>` | 删除指定赛道 |

赛道名称仅允许中英文、数字、下划线与短横线，后端做了路径穿越防护，写入采用临时文件 + 原子替换。

## 参考标准

- **CJJ 193-2012《城市道路路线设计规范》**（车道宽 表5.3.1、圆曲线最小半径 表6.3.2）
- **GB 50647-2011《城市道路交叉口规划规范》**（交叉口进口道宽度）
- **GB/T 36670-2018《城市道路交叉口设计规程》**（进口 / 出口道宽度）
- GB 5768《道路交通标志和标线》
- GB 14887《道路交通信号灯》
- GB/T 24724《道路锥形交通路标》
- 道路施工安全设施（水马、防撞桶、围挡、护栏等）相关国标 / 行业标准

> 说明：本工具中的标志与设施为便于场景编辑所做的示意性 SVG 绘制，标志图形尺寸比例与正式国标图纸并非完全一致，
> 不建议直接用于工程制图或法规合规用途；车道宽度与圆曲线半径等道路尺度参数已按上述国标取值。
