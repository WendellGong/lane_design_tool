1. 分数构成说明 
正式成绩按照以下顺序计算： 
1. 先检查直接归零条件。触发任一项，本局正式成绩直接记为 0 分，不再计算其他得分和扣分，归零
条件详见第4 章。 
2. 未触发直接归零时，将已经完成的八项任务成果分相加，得到任务分，最高 1000 分。 
3. 从任务分中减去普通安全扣分；计算结果低于 0 分时，正式成绩按 0 分计。 
任务分（最高 1000 分） 
= 现场信号确认（最高 240 分） 
+ 封闭道路扫描（160 分） 
+ 中央路口依次通行（最高 200 分） 
+ 指定车位停靠（最高 400 分） 
 
未触发直接归零：正式成绩 = 任务分 - 普通安全扣分 
（计算结果低于 0 分时，按 0 分计） 
触发任一直接归零条件：正式成绩 = 0 分 
 
计算示例：正确确认两个现场信号，获得任务分 160 分。本局发生超速，扣除 50 分；未触发直接归零条
件，正式成绩为 110 分。

3. 普通安全扣分项：每类违规只扣一次 
普通安全违规不会使成绩直接归零。包含超速、急加速或急减速、碰撞三类违规，在本局首次发生
时扣分，之后再次发生不重复扣分；道路边界压线按车辆分别记录，每辆车本局只扣一次。

4. 直接归零项：优先于其他计分 
发生下列任一严重违规或异常越界，无论已经获得多少任务分，本局正式成绩均为 0 分。 
严重违规或异常越界 
触发条件 
穿越封闭道路 
动态路障激活后，任一运输车穿越本局实际封闭道路；封闭道路检测区域以路障中
心线两侧各 7 m 为界 
未授权进入路口 
任一运输车未取得通行权，便进入中央路口中心 6 m 范围内的互斥控制区域 
持续严重越界 
异常越界兜底：任意一辆车的中心超出场景地图边界超过 1.0 米，并连续保持至少 
1.0 秒；不要求正常驾驶主动触发。

附录：地图边界保护说明 
港区陆地边缘设有不可见的防护边界，用于阻挡车辆，防止车辆驶出陆地或坠落。单独接触该边界
不计碰撞扣分；受阻后应停车、倒车或调整路线。该边界不作为任务对象或 static_objects 提供给参赛程
序，也不改变 30 米观测距离、前方 120° 视场及实体障碍遮挡规则。异常越界时，任意一辆车的中心超
出场景地图边界超过 1.0 米，并连续保持至少 1.0 秒，本局结束，正式成绩为 0 分；正常接触防护边界
不会触发此项判定。
