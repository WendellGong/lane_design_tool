# 厂仓物流协同运输场景 · 评分规则（本科组 · 基础版）

## 赛题目标与车辆功能

### 赛题目标

在厂仓物流（厂区仓库物流）协同运输场景中，由程序自动控制多车协同完成物资交付：**按 A → B → C 顺序拾取指定物资 → 由信号车或是运输车扫描动态路障、获取封闭道路信息并重新规划路径 → 两辆运输车先后通过中央互斥路口 → 分别驶抵 A、B 泊位停稳交付**。泊位的精确位置依赖信号确认与多车观测逐步收敛；每车至多交付一个泊位，未完成全部任务时，已完成项按规则计分。

### 车辆功能

任务车辆共 **4 辆**：**2 辆运输车**（卡车）与 **2 辆信号车**（轿车）。

| 车辆 | 数量 / 车型 | 功能与权限 |
|---|---|---|
| **运输车** | 2 辆 / 卡车 | 申请并先后通过中央路口（6 m 互斥区，一车整车驶出并释放通行权后另一车方可进入）；进入 A / B 泊位中心 3 m 范围停稳并提交交付，每车至多交付一个泊位；可提交验证码与目标观测，可触发必经点 |
| **信号车** | 2 辆 / 轿车 | 三信号齐备后驶近动态路障（10 m 范围）执行封闭道路扫描，**信号车或运输车均可**；可提交验证码与目标观测，可触发必经点；不承担路口通行与泊位交付 |

权限要点：

- **验证码（A / B / C）**：对运输车与信号车**同时开放**，任一车辆驶入感应范围提交正确验证码即计分，不要求同一辆车完成全部信号。
- **目标观测**：两类车辆均可提交；信号齐备后，两辆不同车辆的有效观测可使泊位定位达到精确等级。
- **必经点**：不限车型，运输车或信号车中心进入 3 m 范围并保持 0.5 s 即触发（本科组为计分项，专科组为必过门槛并转入手动段）。
- **其他交通参与者**：SUV、巴士、两轮车与行人仅作场景布景或动态障碍，不承担赛题任务。

**设计约束（已验证）**

- 所有轨迹终点均落在**非窄口路段**，不存在永久堵死
- 车辆本体与前进轨迹与既有车辆、信号灯、障碍物、路口的包围盒**零相交**
- 动态车限速不超过 20 km/h，与场景限速一致，不与"超速"判定冲突

**算法要求的变化**

| 能力 | v4（纯静态） | v5（含动态） |
|---|---|---|
| 障碍物表示 | 静态栅格 / ESDF | 需**时空占用预测**（按 moveSpeed × 剩余距离推算） |
| 决策 | 避障 → 通过 | **通行权博弈**：抢行 / 跟随 / 等待的代价比较 |
| 重规划触发 | 静态阻塞时 | 动态目标进入本车走廊且 TTC 低于阈值时 |
| 窄口处理 | 几何收窄 | 几何收窄 + **时间窗对齐**（等动态车让开再进） |

### 1.4 强制绕行：y = 1000 东段封闭

- 封闭区间：`x ∈ [2980, 3820]`，整幅封闭，动态路障即设于 `(3500, 1000)`
- 检测边界：以路障中心线两侧各 **7 m** 为界（13.9 m 宽，覆盖整幅 7 m 路宽）
- 绕行通路（任选其一，均为已建成道路）：
  - `临港南北向道路`：`(2800,1000) → (2800,1960) → (4000,1960) → (4000,1000)`，单程增加约 **260 m**
  - 反向亦可，但需与中横路的 S 弯、中央路口窄口叠加
- 该封闭为**静态封闭**（不依赖扫描结果）：即使尚未完成路障扫描，车辆也不得进入封闭区

### 1.5 难度提升点（对算法的影响）

| 变更 | 原场景 | v4 / v5 | 对算法的要求 |
|---|---|---|---|
| 断面净宽 | 7 m 双向自由通行 | 最窄 3.17 m | 需要精确的**横向偏差控制**与车道级路径生成，不能只做跟线 |
| S 弯 | 无 | 20 m 内两折交错 | 需要**局部重规划 / 样条拟合**，避免大转角导致横向误差超限 |
| 路口进口错位 | 直进直出 | 东西进口各占对侧半幅 | 需要**入口对位 → 穿越 → 出口对位**三段独立规划 |
| 封路绕行 | 全部连通 | 一条主干道断裂 | 需要**全局拓扑重规划**（而非局部避障），且绕行后仍要满足时序 |
| 中央宽通道收窄 | 14 m | 6 m | 4 车道变 2 车道，超车与并线必须重新排布 |
| 施工设施碰撞 | 少 | 17 处 | 需要**障碍物地图维护 + 安全距离缓冲** |
| 动态车辆 | 无 | 6 辆（全场 9 辆） | 需要**动态目标预测 + 通行权博弈 + 时间窗对齐** |
| 窄口 + 动态叠加 | 无 | 6 处窄口与动态车相交 | 需要**时空联合规划**（不能只做几何避障） |
### 1.6 限速区（基础版不设）

本科组基础版**不设 15 km/h 限速区**，全场统一 20 km/h 上限，两条干道（中横路、北侧东西向道路）路侧仅有 v6 遗留的 20 km/h 进口限速提示牌（`fac_l0_limit` / `fac_l1_limit` / `fac_l2_limit`，位于西侧路三个十字路口东侧）。

| 项目 | 本科组基础版 | 本科组进阶版 / 高级版 |
|---|---|---|
| 限速牌数量 | 3 块（20 km/h 进口提示） | 9 块（3 × 20 + **6 × 15**） |
| 判定阈值 | 全场 20.5 km/h | 限速区内 15.5 km/h |
| 相关扣分项 | 仅「超速 −50」 | 「超速 −50」+「限速区超速 −50」 |

> 基础版与进阶版的场景几何、障碍物、动态车、信号灯、标志、泊位**完全一致**，唯一差异就是这两段限速区。因此两组的成绩可在同一基准时间（T₀ = 300 s）下横向比较。

|---|---|---|---|

| 现场信号 | C 号信号 | B 完成后，任一车辆（运输车或信号车）提交正确验证码 | 80 |

> **加分项（时间附加分）**：用时每比基准 **300 s** 少 **1 秒**，即可获得 **2 点**附加分，上限 **+300 分**；慢于基准记 0、不扣分。完整规则与算例见 §3。

> **必经点 `el_mwrj5xwvo1lrw`** 位于 `(4000, 1000)`，即临港南北向道路与 y=1000 行东段的交口，正好落在 y=1000 东段封闭区（`x ∈ [2980, 3820]`）的**外侧绕行转角**上：不完成拓扑绕行就无法到达，取得该项即证明车辆走通了绕行通路。该点为场景内既有元素（`obstacle / beacon`），**不参与碰撞判定**，仅作判定标靶。

### 2.3 定位精度与观测

泊位精确位置取决于**信号确认数量 + 有效观测**：

- 信号未齐备时，观测只能提升到有界精度，交付窗口受限
- 三个信号齐备后，具备**两辆不同车辆**在有效时间窗内提交的合格观测，即可直接达到精确等级（不要求逐级重提）
- 共享定位本身不单独计分，仅影响泊位可交付性与路径规划精度
- **信标验证码（A / B / C）对运输车与信号车同时开放**：任一车辆驶入信号点感应范围并提交正确验证码即计分，不要求三个信号由同一辆车完成（例如运输车提交 A、信号车提交 B、C 同样有效）
- 动态路障扫描**仅限信号车**；中央路口通行与泊位交付**仅限运输车**
- 到达必经点**不限车型**，运输车或信号车触发均计 300 分，但每局只能计一次

## 3. 时间附加分（v3 改版）

### 3.1 基准时间 T₀ = 300 s

本版不再由 40 km/h 理论速度推导基准时间，改为**直接指定 T₀ = 300 s**：口径直观、便于赛前公告，且与进阶版 / 高级版共用同一基准，便于跨组比较。基础版无 15 km/h 限速区，300 s 对本组的余量更大。40 km/h 的理论用时（63.6 s）仅作"物理下界"参考，不是可达目标。

参考里程（沿路网中心线的最短路径，`tools/route_length.py` 可复算）：

| 线路 | 里程 |
|---|---|
| 信号车：起点 → A 号信号 | 287.3 m |
| 信号车：A → B 号信号 | 73.3 m |
| 信号车：B → C 号信号 | 80.0 m |
| 信号车：C → 动态路障（含封路绕行） | 265.7 m |
| **信号车线路合计** | **706.3 m** |
| 运输车 A：起点 → 中央路口 | 214.0 m |
| 运输车 A：中央路口 → A 泊位 | 224.7 m |
| **运输车 A 线路合计** | **438.7 m** |
| 运输车 B：起点 → 中央路口 | 367.3 m |
| 运输车 B：中央路口 → B 泊位 | 304.7 m |
| **运输车 B 线路合计** | **672.0 m** |

三车并行执行，本局用时由最长线路（信号车 706.3 m）决定。按 T₀ = 300 s 折算：

```
L_max = 706.3 m                                    （信号车线路最长）
v_avg = L_max / T₀ = 706.3 / 300 = 2.35 m/s ≈ 8.5 km/h
```

`T_op`（作业与等待）参考构成，沿用 v2 口径，仅作校核：

| 作业环节 | 时间 |
|---|---|
| 3 次信号读取与验证码提交 | 3 × 8 = 24 s |
| 动态路障扫描（驶近 10 m + 扫码） | 10 s |
| 2 次泊位停稳与交付确认 | 2 × 10 = 20 s |
| 中央路口互斥等待（两车依次通行） | 21 s |
| **合计** | **75 s** |

校验：**全程平均 8.5 km/h 即可拿满时间分**——比 15 km/h 限速区低 43%，比全场 20 km/h 上限低 58%。因此避障、窄口对位、路口互斥等待、封路绕行（含新增的必经点折返）都不会危及时间分；`600 s` 时限相对 300 s 基准仍有 2 倍余量。

### 3.2 计分公式

```
ΔT  = T₀ − T_actual            （单位：秒；正值 = 快于基准）
S_t = clamp( 2 × ΔT , 0 , +300 )
```

| 参数 | 取值 | 含义 |
|---|---|---|
| `T₀` | **300 s** | 基准时间（直接指定） |
| `k` | **2 分 / 秒** | 每比基准快 1 秒加 2 分 |
| `S_max` | **+300 分** | 加分封顶 |
| 下限 | **0 分** | 慢于 300 s 不加分，也不扣分 |

即：**实际用时每比基准少 1 秒加 2 分；慢于基准的秒数不计分（记 0），不产生负分。** 时间分只奖不罚，最大影响 +300 分（占任务分 1300 的 23%）。

### 3.3 算例

| 完成用时 T | ΔT = 300 − T | S_t | 说明 |
|---|---|---|---|
| 150 s | +150 | **+300（封顶）** | 等效 16.9 km/h，已超出限速区，实际不可达 |
| 200 s | +100 | **+200** | 等效 12.7 km/h，极限水平 |
| 250 s | +50 | **+100** | 等效 10.2 km/h，优秀 |
| 280 s | +20 | **+40** | 等效 9.1 km/h，良好 |
| 300 s | 0 | **0** | 恰好达标 |
| 360 s | −60 | **0** | 慢于基准，时间分保底 0 |
| 600 s（时限届满） | −300 | **0** | 保底 0，另按未完成结算 |

> **参数可调**：若希望时间分权重更高，可将 `k` 调到 3（此时约 200 s 即封顶）；若希望更弱，取 1。`T₀` 与 `k` 一经赛前公布不得中途修改。

### 3.4 与原有排名规则的关系

- 正式成绩已含时间附加分，仍按正式成绩从高到低排名
- 正式成绩完全相同时，**任务用时较少者**排名靠前（沿用正式版）
- 时间附加分不参与"直接归零"判定，归零局面下成绩恒为 0

## 4. 普通安全扣分（每类只扣一次）

| 违规类型 | 判定条件 | 扣分 |
|---|---|---|
| 超速 | 速度持续 > 20.5 km/h 达 0.5 s | −50（本局 1 次） |
| 急加速 / 急减速 | 加速度绝对值持续 > 5.0 m/s² 达 0.5 s | −50（本局 1 次） |
| 车辆或障碍物碰撞 | 与其它车辆或**正式可碰撞障碍物**（含 v4 新增的锥桶、水马、防撞桶、护栏、围挡）发生物理碰撞 | −100（本局 1 次） |
| 道路边界压线 | 评分轮廓接触主任务道路两侧黄色外边实线并持续 0.2 s | 每车 −50（每车 1 次） |
| **施工设施撞移（新增）** | 锥桶 / 水马 / 防撞桶被撞离原位 > 0.5 m，但车辆未受阻、未触发碰撞判定 | **每次 −50，本局最多 2 次** |

补充口径：

- 压线范围仅限**黄色外边实线**；白色标线、路口开口、中央虚线、停止线、车位标线不计
- 单独接触外围保护空气墙不计碰撞
- 施工设施撞移与碰撞**不重复计分**：若同时满足碰撞判定，只扣 −100

## 5. 直接归零（优先于一切计分）

| 严重违规 | 触发条件 |
|---|---|
| 穿越封闭道路 | 任一运输车进入 y=1000 东段封闭区 `x ∈ [2980, 3820]`（以路障中心线两侧各 7 m 为检测边界） |
| 未授权进入路口 | 任一运输车未取得通行权，进入中央路口中心 6 m 互斥控制区 |
| 持续严重越界 | 任一车辆中心超出场景地图边界 > 1.0 m，且连续保持 ≥ 1.0 s |

v4 补充：**撞倒围挡后继续通行**视为"穿越封闭道路"，同样归零（不得以物理推开设施的方式通过封闭区）。

## 6. 时限与结算

| 情况 | 结算规则 |
|---|---|
| 任务时限 | 600 s，从评分会话开始且场景就绪后计时 |
| 全部完成 | 九项成果齐备且未触发归零 → 立即结束并结算（含时间附加分） |
| 未全部完成 | 600 s 届满按未完成结算；已完成项保留得分，扣除已发生的安全扣分，时间分记 0（慢于基准不加分） |
| 直接归零 | 立即结束，正式成绩 = 0 |
| 系统异常 | 记为无效，不发布成绩，不按 0 分处理 |
| Python 退出 / 断线 | 不暂停计时；控制超时后车辆安全停车，未恢复则 600 s 后按未完成结算 |

## 7. 成绩计算示例

**示例 1（正常完成，有少量违规）**

- 完成：A/B/C 三个信号（240，其中 B 由信号车提交）+ 路障扫描（160）+ 两车通行（200）+ A、B 交付（400）+ 必经点（300）= **1300**

- **正式成绩 = 1000 + 0 − 100 = 900 分**

- 任务分 820，用时 150 s，`S_t = +300（封顶）`
